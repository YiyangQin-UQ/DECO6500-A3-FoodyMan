了解食物在归属、位置和取用许可清楚时，为什么仍可能无人使用，以及哪些改变可能避免浪费。主要方法是个别情境模拟访谈，坏结局作为情境的后续发展。

## 现场准备

| 预计时间 | 内容 |
| --- | --- |
| 0至5分钟 | 阅读参与者说明与同意确认 |
| 5至12分钟 | 真实经历和基础情境 |
| 12至23分钟 | 最后一份及局部角色比较 |
| 23至28分钟 | 继续存放后的判断 |
| 28至37分钟 | 坏结局回推和改变条件 |
| 37至40分钟 | 核对与结束 |

计划访谈2至3名年满18岁、有共享冰箱经历的学生，每人约40分钟。不要求参与者来自同一住处；每人单独访谈，无需实际部署网站。准备本提纲、每人一份记录表，以及参与者说明与同意表。

情境已经整合在第2至4页。现场只照读或展示标明的情境文字，后面的追问由访谈者掌握，不提前展示坏结局或研究者假设。用P01等编号；不要记录室友姓名或住址。

## 开场说明

“谢谢你参加。这是我的DECO6500 A3课程访谈，大约40分钟。我们先聊共用冰箱的经历，再讨论假设情境。没有标准答案，你可以不同意情境、说不确定、跳过问题或随时停止。请不要提室友姓名或其他可识别信息。”

“请先阅读参与者说明。原始资料仅保存在我的本地个人设备，课程结束后删除。提交的只有去除身份信息的分析，不包含录音、完整访谈记录或签名表。录音和简短原话引用分别由你选择。”

按正式同意表逐项确认参与、录音、去标识原话引用并签署；给参与者保留一份。拒绝录音时只记笔记；未同意引用时只作概括。提交前可联系研究者〔个人联系方式已省略〕要求排除回答并删除访谈文件，提交后已交出的分析可能无法撤回。具体权利和安排以参与者说明为准。

## 真实经历与当前选择

### 先聊真实经历

Q1  你以前怎样和别人共用冰箱？

可追问：彼此熟悉吗？通常怎样知道谁的食物可以拿？

Q2  你有没有遇到过食物放了很久却一直没有被使用的情况？请讲一次具体经历。

可追问：当时你想不想吃？实际做了什么？知道什么、还不确定什么？后来怎样了？这些是亲自经历、听说，还是现在回想的判断？

没有类似经历时，可问一次共享食物被顺利取用的事件；仍没有则记“无相关回忆”并进入情境。不要把参与者对别人的猜测写成别人的真实想法。

### 情境一 允许取用的食物

照读或只展示以下情境文字

假设你和室友共用冰箱，并使用FoodyMan查看食物属于谁、放在哪里、是否允许别人取用。冰箱里有一份属于另一位室友、你本来愿意吃的冷冻食品，已经存放了一段时间。它没有占用你急需的空间，也没有造成即时困扰。网站清楚显示了主人、位置，并标明你可以取用。没有说明的细节，你可以提出自己还需要知道什么。

Q3  在这个情况下，你现在会怎样决定是否取用？

可追问：你是想吃但暂时不拿、不想吃，还是会直接拿？为什么？你最需要先确认什么？

Q4  网站上写着“可以取用”，对你来说意味着什么？

可追问：你会怎样理解主人的意思？哪些事情已经清楚，哪些仍需要确认？如果完全不需要再问，也请说明理由。

先记录开放回答，再进入下一页。不要提前给出“不是自己的所以不敢吃”或“存放越久越担心”等原因。对方认为情境不符合自己的经验时，记录哪里不同及其影响。

## 最后一份与局部角色比较

### 情境二 这是最后一份

照读或只展示以下情境文字

保持刚才的情况不变。现在你得知，这是主人留下的这一类食品的最后一份，FoodyMan仍显示你可以取用。

Q5  知道这是最后一份以后，你会不会改变刚才的决定？

可追问：如果改变，改变在哪里、为什么？如果不变，什么使你仍能按原来的决定行动？

### 只在这里比较两种身份

以下A和B是同一位参与者分别考虑的两种身份，不需要两人共同表演。每次明确正在从谁的角度回答；这些回答不能代表真实室友的想法。

A 食物主人  假设这份食物是你的，你把它设为可以分享。你自己还想吃吗？接下来会怎样安排它？

可追问：若还想吃却一直没有吃：是什么使你推迟？若不打算吃：你希望别人怎样处理？你是否介意别人拿走最后一份？你希望先被询问吗？

B 其他舍友  现在换成另一位舍友，你愿意吃这份食物，也看到允许取用。你会拿走这最后一份吗？

可追问：如果想吃却不拿，你在顾虑什么？你会怎样知道主人是否还想留着？如果直接拿，是什么让你确定这样合适？

Q6  比较这两种身份，有没有彼此可能理解不同的地方？

可追问：主人不吃，与舍友想吃却没有拿，理由相同吗？也可能没有分歧；请按你的判断说。

### 按回答自然补问

只补问尚未解释清楚的地方，例如：“你需要知道什么才能决定？”“实际取用或准备食物有什么困难？”“什么时候才有机会吃？”“你觉得对方会怎样理解？”“你最在意哪种结果？”“看到它时第一反应是什么？”这些问题不必全部问。

COM-B留作访谈者理解和后续分析的参考。优先追问参与者自己的词语；没有明显关联的类别留空，不为覆盖类别而追加问题。

## 继续存放与坏结局回推

### 情境三 过了一段时间

照读或只展示以下情境文字

接着情境二，假设又过了一段时间，这份食物仍没有被使用，也没有造成即时困扰。你可以说明自己理解的“一段时间”有多长；如果你认为食物早就会被吃掉或处理，也请说出来。

Q7  和最初相比，你现在会怎样判断和行动？

可追问：什么改变了，什么没变？什么信息或事情会促使你采取行动？如果你认为它不会继续搁置，在哪里会中断？

记录参与者采用的时间和原因，不设精确时间点，不暗示时间必然增加顾虑。保留“没有变化”的回答。

### 情境四 搬家时仍被丢弃

照读或只展示以下情境文字

现在假设到了学期末搬家时，冰箱里仍有一些长期未被使用的食物，最后被丢弃。这些食物在FoodyMan上的归属、位置和取用许可一直清楚。我们先把它当作一个可能的坏结局，讨论它怎样可能发生；你也可以指出不合理的地方。

Q8  从这个结局往前看，之前可能发生了什么？

可追问：哪些是你经历过的，哪些是对这个情境的推测？还有哪些不同原因能导致同样的结局？

Q9  如果想避免这个结局，之前哪个时刻最有机会改变？

可追问：谁需要在什么时候做什么？为什么可能有用？会增加谁的负担，或带来什么不舒服？有没有不用网站就能做到的办法？

Q10  如果最后要处理掉食物，谁可以决定？

可追问：允许拿来吃是否也包括允许丢弃？需要谁同意、什么理由？更早清理与真正被吃掉，分别意味着什么？

### 先听建议 再按需要比较改变条件

C1：回到情境二，主人直接说“这份我不打算自己吃了，你想吃就拿，不用再问我”。C2：另一次回到情境二，只有实际已知的存放日期和保存方式变得更清楚。两项不叠加；信息清楚不代表已证明安全。

每项追问：“你的决定会改变吗？解决了什么，还有什么没解决？为什么？”记录展示顺序；时间不足可跳过并记原因。此处不重新要求完整A/B角色比较。

## 核对与访谈后整理

Q11  我理解你刚才的意思是……这样准确吗？

可追问：分别核对真实回忆、情境判断和建议。还有什么会改变你的判断？有没有不希望记录或引用的内容？

“谢谢你的参与。如需补充或询问资料使用，可以联系研究者〔个人联系方式已省略〕。”

### 回路只在最后必要时核对

自由讨论结束后，若仍需核对，可以说：“我在考虑一种解释：有人有顾虑所以推迟取用，放得更久后顾虑又增加。它符合你的想法吗？哪一段不成立？什么时候会中断？”记录是否问过、何时问过；提示后的认可不能当作参与者主动提出。

### 每场结束立即填写运行笔记

为重要回答标E01等证据号，附录音时间或笔记位置。区分真实经历的回忆、情境中的预期选择、建议、研究者解释；没有录音时标清哪些是原话、哪些是概括。记录跳题、顺序变化、额外提示和参与者对情境的质疑。

## 方法评价标准

| 标准 | 用什么判断 |
| --- | --- |
| 1 解释决定与顾虑 | 获得具体选择及其理由，能区分想吃与实际取用、主人与舍友的不同判断；按相关性分析COM-B因素并记录缺口。 |
| 2 理解时间中的变化 | 能比较初始与继续存放后的判断，指出改变、不变或中断的条件及理由。 |
| 3 检查回路与替代解释 | 能记录支持、反对或修正回路的回答，以及其他原因；区分主动提出和提示后回答。 |
| 4 建议有证据和承担者 | 建议对应具体回答，说明谁何时做什么、为何可能有用及可能负担；识别未解决问题。 |


小样本最多支持这些参与者对可能机制及改变条件的解释；不能证明回路的因果关系、普遍性、网站有效性或现实减废效果。

## 保存与分析

原始资料仅保存在受密码保护的本地个人设备，身份及同意记录与编码访谈分开。课程结束删除原始资料及本地备份；不上传原始采访资料到外部AI或云端。仅提交去标识后的分析和经单独同意的简短原话。COM-B分析优先依据回答，不强行填满类别。
